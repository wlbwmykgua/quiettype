# QuietType English v1.0

Frozen on 2026-07-21 as the retained English typing-practice version.

## Behavior

- Displays the current English word and one upcoming word in a compact floating panel.
- Keeps both words baseline-aligned and automatically fits the panel width to their content.
- Accepts every typed letter; correct letters are green and incorrect letters show in red.
- Incorrect input must be removed manually with Backspace before the word can complete.
- Completing the exact target word advances automatically.
- `Esc` hides the panel; the menu-bar cursor icon restores it.

The installed application is `/Applications/QuietType.app`.
